# 쿠폰 정산 대조

쿠폰사 정산 자료와 내부 자료를 샘플로 비교합니다. 금액·수량·누락을 보여주고, 둘 다 같은 건만 인보이스와 전표로 만듭니다. 실제 회사 자료가 아니고, 유료 서비스는 쓰지 않습니다.

## 실행

`열기.cmd`를 더블클릭합니다. 브라우저에서 http://127.0.0.1:3460 이 열립니다.

## 확인

화면이 열리면 파일 칸과 ‘올린 파일로 대조’ 버튼만 보입니다. 결과는 파일을 고르고 그 버튼을 누른 뒤에만 나옵니다. 새로고침하면 결과는 다시 사라집니다. csv와 xlsx를 받을 수 있습니다.

- 쿠폰사 정산 파일: `업체전달샘플_쿠폰사_정산내역.csv`
- 가맹점 내부 자료: `업체전달샘플_가맹점_내부자료.csv`

- 금액이 다른 건: C-1003
- 수량이 다른 건: C-1005
- 정산에만 있는 건: C-1004
- 내부에만 있는 건: C-1006
- 인보이스와 전표: C-1001, C-1002, 합계 35,000원
