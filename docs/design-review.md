# 디자인 리뷰 — 쿠폰 정산 대조 (첫 화면)

검토 화면: 로컬 앱 첫 화면(파일 두 개 올리고 대조). 결과 카드·표는 레이아웃만 영향 없는지 확인했고, 대조 API·샘플 데이터·업무 카피 의미는 바꾸지 않았다. 베이지 배경(`#f4f1ea`)·녹 버튼(`#0f6e56`)을 유지했다.

## 고친 것

| 심각도 | 위치 | 이유 | 수정 |
| --- | --- | --- | --- |
| 중요 | 업로드 폼 파일 입력 | 한글 UI인데 브라우저 기본 `Choose File` / `No file chosen`이 남아 업무 도구처럼 보이지 않음 | 네이티브 `input[type=file]`은 시각적으로 숨기고, `파일 선택` + `선택된 파일 없음`을 표시. 선택 후 파일명은 소량 JS로 갱신 |
| 중요 | `.upload` 패널·제출 버튼 | `main`이 1100px라 흰 패널과 녹 버튼이 가로로 늘어나 첫 화면이 비어 보임 | `header`를 약 44rem으로 묶음. 파일 두 칸은 데스크톱에서 2열. 제출 버튼은 내용 너비만 |
| 경미 | `#report` 빈 안내 | 결과 영역이 1100px 전체라 안내 한 줄이 동떨어져 보임 | 표가 없을 때만 헤더와 같은 폭. 결과가 나오면 기존처럼 넓게 펼침 |
| 경미 | 본문 줄바꿈 | 폭을 줄인 뒤 한글이 음절 단위로 잘릴 수 있음 | `word-break: keep-all` |

## 남긴 것

| 심각도 | 위치 | 이유 | 남긴 이유 |
| --- | --- | --- | --- |
| — | `/api/reconcile`, `/api/sample`, 업로드 payload | 기능 범위 밖 | 디자이너 범위에서 API·샘플·비즈니스 로직 금지 |
| — | 안내 문구·샘플 파일명 | 의미 유지 | 줄바꿈·계층만 다룸. 카피 의미 변경 없음 |
| 경미 | 결과 화면 카드·표 | 이번 요청은 첫 화면 | 색·타이포는 기존 토큰 유지. 표 밀도·카드 배치는 후속 검토 |
| 경미 | `.muted` `#5d6672` | AA에 가까운 본문 대비 | 연한 회색은 아님. 브랜드 색 교체 금지에 따라 유지 |
| — | 새 폰트 CDN | 기존 `Malgun Gothic` / `Apple SD Gothic Neo` | 새 라이브러리·폰트 추가 없음 |
